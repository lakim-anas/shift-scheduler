# Shift Scheduler

A Java command-line tool that builds a weekly staff schedule from employee availability and a store's opening hours.

## Why I'm building this

I managed a store with a team of 16 for four years. Building the weekly schedule by hand took hours, and one change could break the whole week. This project is the tool I wanted back then.

## Status

In progress. Version 1 is being built step by step.

## Planned features (version 1)

- [ ] Model employees, shifts, and availability as Java classes
- [ ] Read employees and availability from a CSV file
- [ ] Assign employees to shifts without double-booking
- [ ] Respect a maximum number of hours per employee
- [ ] Print the weekly schedule in the terminal
- [ ] Unit tests with JUnit

## Roadmap

- Version 2: store data in a SQL database
- Version 3: REST API with Spring Boot
- Version 4: web front end
